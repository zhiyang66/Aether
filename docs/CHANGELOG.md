# Changelog

## 1.0.5 — 当前版本（2026-07-27）

- Agent 操作轨迹改为中文动作、目标和状态的时间线；原始工具输出按需展开，不再直接堆叠 JSON 与终端内容
- 终端维持等宽对齐，同时提高字重以匹配 Agent 正文的可读性
- 移除无效的 Agent「思考」切换按钮，思考过程默认始终显示
- 更新检查支持 GitHub Releases 安装包直链，在软件内下载并启动 Windows 安装程序

## 0.6.0 — 当前冻结版（2026-07-24）

**状态：当前对外版本。** 后续功能开发默认挂在 0.6.0 上，**等你评定后再升号**。

### 相对 0.1.0 累计能力

- 工作台 / 设置（prototype 视觉）、多标签、树状分屏、窗格 #N
- Mock 终端 + Tauri 真 PTY / xterm、OSC7 cwd、输出快照（可选）
- 命令历史与联想（含 xterm 浮层）、命令面板
- Agent：endpoint 模型列表、会话与搜索、#N 插入/运行、危险确认
- 任务模式：`/task`、任务面板（执行/跳过/下一步/重试/标失败）
- 工作区（设置页 + 命令面板）、内置布局模板、自定义布局模板
- 扩展：官方示例、导入 JSON、启用/移除、命令进面板
- 主题预设、欢迎条、导入/导出工作台、焦点窗格最大化
- 关于页检查更新（仅提示）
- 工程：单元测试、`npm run check` / `release`、前端 CI

### 版本说明

- 0.4 / 0.5 能力未单独长期钉 package，统一收口在 **0.6.0**。
- 曾误标 2.0.0 / 2.1.0，**作废**；2.0.0 仅在你确认后才可启用。
