# Changelog

## 1.0.7 — 当前版本（2026-07-28）

- 终端 `Ctrl+Enter`：在 Codex / Claude 等全屏 TUI 输入框插入换行（不提交）；编码对齐其原生有效的 Alt+Enter（`ESC CR`），普通 Shell 仍用各自行编辑序列
- 设置 → 快捷键表补充「插入换行」「行首 / 行尾」
- Codex Working 动画重绘：写入期间冻结 xterm 硬件光标，降低路径文字上的多余光标闪烁；组字时尝试钉住 IME 位置（仍可能受系统 IME 影响）
- Agent 回复气泡右下角增加一键复制图标（复制 markdown 原文）
- 移除流式回复气泡末尾的闪烁伪光标

---

## 1.0.6 —（2026-07-27）

- 更新检查增加检查中状态、应用内安装包下载进度和安装程序启动重试，避免下载完成后文件仍被占用导致安装失败
- 终端粘贴统一走防护路径：保留多行粘贴边界、拒绝不安全的 `cmd` 多行输入，并可识别剪贴板图片、保存后插入安全引用的本地路径
- 修复 `Home` / `End` 行首行尾跳转；`Ctrl+Enter` 可在 PowerShell、Bash、Zsh、WSL 和 SSH 的交互编辑区插入换行而不执行命令
- Agent 自动执行仅允许短单命令，阻止 heredoc、复合 shell 语法和超长命令损坏远端会话；相同 SSH 主机在一次任务中禁止重复连接，远端关闭后改为读取日志并诊断
- Agent 创建或操作后台终端标签不再切走用户正在查看或输入的 Shell；终端初始化也不会抢占 Agent 输入框焦点
- Agent 输出、思考和操作记录自动跟随到最新位置；操作记录采用可折叠的中文动作时间线，Shell 字体提高字重，默认显示思考过程并移除无效开关
- Agent 生成期间可即时追加需求，追加内容可编辑或删除；Agent 回复提供复制操作
- Agent 和 Shell 均支持粘贴图片；发送给 Agent 的图片会保留在聊天记录中，并支持点击放大预览
- Agent 工具调用增加风险意图标记，并对只读查询降低误报；危险操作仍由本地策略和用户确认兜底

## 1.0.5 — 当前版本（2026-07-27）

- Agent 操作轨迹改为中文动作、目标和状态的时间线；原始工具输出按需展开，不再直接堆叠 JSON 与终端内容
- 终端维持等宽对齐，同时提高字重以匹配 Agent 正文的可读性
- 移除无效的 Agent「思考」切换按钮，思考过程默认始终显示
- 更新检查支持 GitHub Releases 安装包直链，在软件内下载并启动 Windows 安装程序
