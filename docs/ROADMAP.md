# Aether · 路线图（0.6 → 1.0）

**当前对外版本：`0.6.0`（冻结基线）**  
**目标重大版：`1.0.0`**（稳定、可分发、Agent 工作流可用）

| 位置 | 版本 |
|------|------|
| `apps/desktop/package.json` | 0.6.0 |
| `apps/desktop/src-tauri/tauri.conf.json` | 0.6.0 |
| GitHub Release | [v0.6.0](https://github.com/zhiyang66/Aether/releases/tag/v0.6.0)（Windows x64） |

### 版本纪律

1. **0.6.0** 为已发布基线；补丁默认可挂 0.6.x，**不擅自跳到 1.0**。  
2. 中间里程碑建议：**0.7 → 0.8 → 0.9 → 1.0**，每级可验收、可发预览包。  
3. **1.0** 仅在你确认「作为 1.0 发布」后改版本号 + CHANGELOG。  
4. 历史误标 **2.0.x 作废**；重大版叙事统一为 **1.0**。  
5. 归档文档见 [`archive/`](archive/README.md)。

## 0.6 基线（已有）

- 工作台：多标签、树状分屏、#N、命令面板、布局/工作区  
- 终端：真 PTY + xterm、OSC7、历史联想、右键菜单、Ctrl+C/V/L  
- Agent：OpenAI 兼容 endpoint、会话、tool loop、#N 插跑、危险确认  
- 任务：`/task` 手动多步清单 + 任务面板（**非**对话自动规划）  
- 扩展 / 主题 / 导入导出 / Windows 安装包（NSIS + MSI）

**已知缺口（驱动 0.7+）：**

| 缺口 | 影响 |
|------|------|
| `/task` 仅手动；模型不会自动拆步 | 任务面板使用率低 |
| 步骤解析弱（依赖 `#N: cmd` / 反引号） | 易建出「无 command」不可执行步 |
| 执行后即标 done，不看真实退出码 | 任务可信度差 |
| 无代码签名 / SmartScreen | 分发摩擦 |
| 无 macOS/Linux 正式包、CI 不打桌面包 | 跨平台 1.0 不完整 |
| Agent 上下文/工具边界仍偏「能用」 | 复杂场景易失手 |

---

## 规划原则（1.0 之前）

1. **终端优先可靠**：快捷键、剪贴板、清屏、中断、焦点 — 不回归。  
2. **Agent 可验证**：能读窗格、能跑命令、任务步骤可追踪，而不是「聊天玩具」。  
3. **Windows 先稳**：1.0 以 Windows x64 为主交付；macOS/Linux 能跟则跟，不阻塞核心。  
4. **少而深**：不并行开 SSH / 云同步 / 插件市场等大项，除非单独排期。  
5. **可发布**：每个 0.x 结束应能打出 Windows 安装包并写清变更。

## 里程碑建议

### 0.7 — 可靠补强（Polish）

**目标：** 0.6 日常使用「不硌手」。

| 项 | 说明 |
|----|------|
| 终端快捷键回归 | Ctrl+C/V/L、选区复制、粘贴、清屏自动化/手测清单 |
| 右键菜单 | 复制/粘贴/清屏/分屏全路径手测 |
| `/task` 解析增强 | 支持 `#N cmd`、`#N：cmd`、列表行、无冒号常见写法；无 command 时引导 |
| 任务面板体验 | 空状态文案、示例一键创建、步骤编辑（改 command） |
| 文档 | 现行 README / ROADMAP / CHANGELOG 与代码一致 |
| 发布 | 可选 0.7 Windows 预览包 |

**不做：** SSH、自动更新安装、大改 UI。

---

### 0.8 — Agent 工作流（Workflow）

**目标：** 任务面板成为「Agent 干活」的主路径之一。

| 项 | 说明 |
|----|------|
| 对话 → 任务 | 模型按约定结构输出多步计划，一键落入任务面板 |
| 步骤状态 | 执行后根据输出/超时/可选退出码更新 done/failed（至少启发式） |
| Tool 对齐 | tool loop 与任务步骤可关联（哪步调用了哪个工具） |
| 上下文 | 窗格输出摘要、危险命令、#N 解析更稳 |
| `/task` 与自然语言 | 「帮我列检查步骤」与 slash 殊途同归 |

**验收：** 用户用自然语言要「三步检查」，面板出现可执行步骤，且逐步执行有反馈。

---

### 0.9 — 平台与分发（Ship）

**目标：** 安装、更新、工程化接近产品。

| 项 | 说明 |
|----|------|
| Windows 签名（可选但推荐） | 降低 SmartScreen 拦截 |
| CI 打 Windows 包 | tag / release 工作流上传 NSIS/MSI |
| 检查更新可用 | 关于页指向 GitHub Releases `version.json` 或 API |
| 扩展 | 目录热加载或更稳的导入校验（二选一做深） |
| 稳定性 | 崩溃边界、PTY 异常重开、长会话内存 |

**可选支线（不挡 1.0）：** 多窗口 / 拖出标签；macOS 包。

---

### 1.0 — 稳定版（GA）

**目标：** 「可推荐给别人装」的 Windows 终端工作台。

| 门槛 | 标准 |
|------|------|
| 终端 | 日常 Shell 使用无阻断缺陷（中断/粘贴/分屏/标签） |
| Agent | endpoint 配置后可对话；#N 读写跑稳定；任务流可用 |
| 分发 | 签名或明确未签名说明 + GitHub Release 流程可复现 |
| 质量 | `npm run check` 绿；关键路径手测清单过关 |
| 文档 | 安装、配置 Agent、快捷键、任务用法齐全 |

**1.0 明确不做（除非你改范围）：**

- 远程 SSH 主机管理  
- 云同步账号 / 多人协作  
- 插件市场、主题商店  
- 快捷键可视化重映射编辑器  
- 嵌入系统终端窗体
