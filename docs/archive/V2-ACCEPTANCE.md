# 2.0 发版门槛（仅当你决定升 2.0 时使用）

## 当前版本

**对外版本是 0.6.0，不是 2.0.0。**

0.6.0 已包含下列能力，但**版本号保持 0.6.0**，直到你明确要求改为 2.0.0。

| Major 能力 | 0.6.0 代码 |
|------------|------------|
| 命名工作区 | ✅ |
| 布局模板 | ✅ |
| Agent 任务模式 | ✅ |
| 扩展挂钩 | ✅ |
| 输出快照 | ✅ |

## 升 2.0.0 时你需要做的裁定

- [ ] 确认「本版作为 2.0 重大版发布」
- [ ] 上表手动验收通过
- [ ] 允许修改：`package.json`、`tauri.conf.json`、关于页、`CHANGELOG`、`ROADMAP`

在完成裁定前，开发可继续，**默认不升版本号**。

## 2.0 之后仍可单独排期

SSH、扩展热加载、自动安装更新、多窗口、CI 桌面打包、任务并行等。
