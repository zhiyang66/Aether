# Shell Workbench · 版本与路线

## 当前冻结版本：**0.6.0**

| 位置 | 版本 |
|------|------|
| `apps/desktop/package.json` | **0.6.0** |
| `apps/desktop/src-tauri/tauri.conf.json` | **0.6.0** |
| 设置 → 关于 | **v0.6.0** |

**版本纪律（即日起）：**

1. **0.6.0 为当前对外稳定号**，表示 0.1～0.6 规划能力已收口到本号。  
2. **后续新功能默认不升版本号**，除非你评定后明确说升到某号（如 0.7.0 / 2.0.0）。  
3. **禁止跳号**（例如不能从 0.3 直接标 2.0）。  
4. **2.0.0 仅在你确认「发重大版」后**再改三处版本号 + CHANGELOG，不得自行顶上去。

## 已走完的版本阶梯（历史）

| 版本 | 阶段 | 说明 |
|------|------|------|
| 0.1.0 | V1.0 基线 | 工作台/设置、分屏、#N、mock+PTY、Agent 基础 |
| 0.1.1 | V1.1 质量 | 测试、OSC7、消毒、关窗策略等 |
| 0.2.0 | V1.2 体验 | xterm 联想、拖拽标签、主题、欢迎条等 |
| 0.3.0 | V1.3 | 任务面板初版、工作区 UI 入口 |
| 0.4.x～0.5.x | V1.4～V1.5 | **未单独长期钉 package**；能力合入后由 **0.6.0 收口** |
| **0.6.0** | V1.6 收口 | **当前冻结**；含任务重试、扩展 UI、自定义模板、更新检查等 |

误标过、**已作废**的号：`2.0.0`、`2.1.0`（曾错误使用，已改回 0.6.0）。

---

## 0.6.0 能力范围（摘要）

- 终端：多标签、树状分屏、#N、PTY/xterm、联想、快照（可选）  
- Agent：endpoint 模型、会话、#N 执行、任务面板、多动作、消毒  
- 平台：工作区、布局模板、自定义模板、扩展管理  
- 工程：单元测试、`npm run check`、前端 CI、发布文档
