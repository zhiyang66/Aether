## 快速开始

```bash
cd apps/desktop
npm install
npm test
npm run check
npm run tauri:dev   # 或 npm run dev（浏览器 mock 终端）
```

产品说明与快捷键：[`apps/desktop/README.md`](apps/desktop/README.md)。
